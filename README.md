# IndieKing

Unity game project using the Universal Render Pipeline (URP).

## Requirements

- Unity Editor **2022.3.62f2c1**
- Universal Render Pipeline **14.0.12** (resolved through Unity Package Manager)

## Getting started

1. Clone this repository.
2. In Unity Hub, add the cloned project folder and open it with the required Editor version.
3. Wait for Unity to restore packages and import assets.
4. Open `Assets/Scenes/SampleScene.unity`.

`Assets`, `Packages`, and `ProjectSettings` are tracked in Git. Unity caches, local editor settings, and generated IDE files are ignored.
